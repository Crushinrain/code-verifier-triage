## 最短阅读路径

1. `01_总体方案与研究设计.md`：确认研究问题、系统边界、Gate 与停止规则；
2. `02_Agent执行手册.md`：确认 Agent 权限、任务生命周期和各 Gate SOP；
3. `../contracts/project.yaml` 与 `../contracts/upstream.lock.yaml`：确认项目状态和上游版本；
4. `../tasks/task_graph.yaml`：按依赖领取任务；
5. `../checklists/gate0.md`：从 Gate 0 开始，不允许跳 Gate。

## 机器可读资产

- `contracts/`：14 份冻结合同；
- `schemas/`：6 份数据对象 Schema；
- `tasks/`：69 项任务、Gate matrix 与周计划；
- `prompts/`：Agent 角色合同；
- `templates/`：run、实验、评审、失败、Claim 与证据模板；
- `scripts/`：执行包校验、合同冻结、run 初始化和 artifact hash 工具。

## 首次运行

```bash
python -m pip install -r requirements-agent.txt
python scripts/validate_bundle.py
python scripts/check_contract_freeze.py --help
python scripts/new_run.py --stage G0 --method preflight --seed 0
```

在 Gate 0 人工批准前，只允许执行 T000–T023 中不涉及 policy 训练的任务；禁止访问 sealed final test，禁止在宿主机直接执行候选代码。
